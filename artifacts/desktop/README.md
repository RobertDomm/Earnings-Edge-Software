# EE Software Screener — Desktop App

An Electron wrapper around `https://eesoftware.app/screener`. Members download the installer, launch it, and it opens in a native window. Auth is handled by Clerk + Circle exactly as the web app — membership is re-verified on every launch.

## How installers are built

Pushing any change to `artifacts/desktop/` on the `main` branch triggers the [GitHub Actions workflow](../../.github/workflows/desktop-release.yml), which builds on real Mac, Windows, and Linux runners and publishes a GitHub Release at:

```
https://github.com/<org>/<repo>/releases/tag/desktop-latest
```

You can also trigger it manually from the Actions tab.

## What to post in Circle

```
📥 Download the EE Software Screener desktop app:

Mac:     [EE-Software-Screener-x64.dmg / arm64.dmg]
Windows: [EE-Software-Screener-Setup.exe]
Linux:   [EE-Software-Screener.AppImage]

First-time install:
• Mac — Right-click the .dmg → Open → click "Open" (unsigned app warning, one-time only)
• Windows — Click "More info" → "Run anyway" in the SmartScreen dialog (one-time only)
• Linux — chmod +x *.AppImage, then run it

Sign in with your Circle email. Access is verified automatically — if your membership
is ever removed, you'll be redirected to the sign-in page on next launch.
```

## Local development

```bash
cd artifacts/desktop
pnpm install
pnpm start          # opens the app pointing at eesoftware.app/screener
```
